# Server permission update

The bots are Jerry, Chrisp Utility and Chrisp AI. The shared white The Wise Ones role is a display grouping only; its permissions have been cleared. Each bot keeps its own scoped permissions. The owner retains Discord's inherent server-owner powers.

The Moderator role has Manage Messages, Moderate Members, Kick Members and Ban Members, without Administrator. Staff-only channels and transcripts remain private. Posting-only channels deny messages and both public/private thread creation. Config sharing keeps posting enabled with a 15-second slowmode. Existing role colours and the current server name are preserved.

Automatic Member assignment waits until the user's first successful server message, so assigning a role does not bypass Discord's verification requirement. Welcomes remain enabled.

Join-burst protection alerts staff. It does not automatically kick, ban, quarantine or lock down newcomers. Message moderation handles mass mentions and coordinated unapproved links. The server's current native Discord AutoMod rules are preserved.

Backups exclude credentials. Download an independent backup: copies on the same host do not protect against losing that host. The free host requires manual renewals. Server header banners depend on Discord boost eligibility.

Owner account security and trusted staff remain essential; this configuration cannot make a server immune to harm.
